// CORE_PRINCIPLES

社群核心理念

六条底线，筛选认同这些价值观的伙伴。索取型心态会在答辩阶段被筛除。

01

共建自治

社群不属于任何个人，资产、规则由成员共同维护。发起人离开，认同规则的伙伴仍可继续运转。

02

迭代实践

持续产出带思考迭代记录的作品，拒绝空想。重视思考过程，而非单纯看最终成果好坏。

03

理性互评

互评是互相校验思路，不是互相吹捧或人身攻击。鼓励接收合理意见，警惕重度傲慢。

04

拒绝闭门造车

遇到卡点鼓励交流。公域禁止持续宣泄负能量，情绪压力交由轮班树洞官承接。

05

筛选优先

只接纳认同理念、愿意双向付出的实践者。社群不提供赚钱方案，不承诺收入与机会。

06

合规底线

严禁讨论时政敏感话题，禁止任何违法违规言论与行为。触碰红线，直接移出社群。

// APPLICATION_PROCESS

申请流程

全程人工评审，不看你作品多厉害，只看你是否在持续思考、是否愿意双向付出。

1

阅读全部公开文档

仔细阅读 README、风险声明、报名指南，确认你理解：社群不提供赚钱方案、需要每月交付作品、要参与共建。

2

准备你的实践作品

任意类型作品均可：编程、写作、产品调研、创作复盘。硬性要求：放在你自己的 GitHub 仓库（Gitee 可备选），配套 MD 文档记录思考过程、试错与迭代，仓库有多条 commit 历史。不评判技术水平高低。

3

提交申请 + 缴纳评审费

填写申请表，提交个人信息和作品仓库链接，缴纳 199 元评审费。评审费用于过滤低重视度申请、补偿人工评审时间。

初审不通过全额退款
4

人工初审

审核仓库 commit 迭代记录和 MD 思考文档。通过则预约一对一语音答辩；不通过则全额退款，不安排答辩。

5

语音答辩（15–30 分钟）

核心环节。考察真实动机、迭代思维、接纳意见的能力。不考口才。申请者可自愿开启内部旁听，敏感内容可随时关闭。

答辩不通过全额退款
6

通过即入群

分配编号 S-XXX，评审费转入社群公共共建基金。开始参与月度作品提交、互评、树洞官轮值、共建工作。

// FAQ

常见问题

申请前建议看完这些。

交钱就一定能加入社群吗？
不能。缴纳 199 元评审费仅代表获得评审资格，最终录取取决于作品迭代记录与语音答辩。初审不通过或答辩不通过均全额原路退款。交钱不等于入群。
答辩开启旁听，我的商业想法会泄露吗？
旁听是自愿选项，你可以直接选择一对一语音不开启旁听。答辩过程中，只要你认为内容敏感，可以随时要求关闭旁听，切换私密对话。
如果招募窗口期结束，合格人数不足10人会怎样？
本次种子招募终止，社群项目放弃。已经提交申请的评审流程照常完成。已答辩通过的伙伴另行协商处理方案。
进入社群之后，编号代表等级高低吗？
编号仅作为档案记录标识，S 代表 Seed 种子伙伴，顺序编号，没有任何层级、权益高低之分。权益只绑定月度作品交付与共建贡献。
社群交流有哪些红线不能碰？
所有成员必须遵守国家法律法规。社群内禁止讨论时政敏感内容，禁止发表违法违规言论。触碰合规红线会被直接移出社群。
我在国内访问 GitHub 不稳定，可以用其他平台放作品吗？
可以。GitHub 为主选平台，如国内访问不便，可使用 Gitee 作为备选。仓库必须配套 MD 思考文档和多条 commit 迭代记录，平台不影响评审标准。
答辩失败后多久可以重新申请？
本次审核失败，3 个月后方可携带新作品再次提交申请。再次申请需要重新缴纳评审费。
无故缺席答辩会怎样？
提交申请、预约答辩后，无故缺席或临时取消且无合理理由，评审费不予退还。合理理由包括突发疾病、家庭紧急事务、重大设备或网络故障等不可抗因素，需在答辩前 24 小时告知并事后说明。
加入后需要做什么？
每月提交一份带 GitHub 仓库、MD 文档、多条 commit 迭代记录的实践作品；参与交叉互评；自愿承担部分共建事务（树洞官轮值、文档维护、评审协助等）；参与社群规则迭代讨论。社群不是付费圈子，需要付出时间精力共建。
