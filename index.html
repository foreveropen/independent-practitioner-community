社群核心理念

六条底线，筛选认同这些价值观的伙伴。索取型心态会在聊天阶段被筛除。

01

共建自治

社群不属于任何个人，资产、规则由成员共同维护。发起人离开，认同规则的伙伴仍可继续运转。

02

实践复盘

每天记录做了什么、卡在哪、怎么处理的。一个月后这些记录自然攒成一份复盘。不追求最终成果好看，重视过程中的真实思考。

03

理性追问

互相校验思路，不是互相吹捧。问具体问题：备选方案呢？执行了没有？警惕重度傲慢。

04

拒绝闭门造车

遇到卡点鼓励交流。公域禁止持续宣泄负能量，情绪压力交由轮班树洞官承接。

05

筛选优先

只接纳认同理念、愿意双向付出的实践者。社群不提供赚钱方案，不承诺收入与机会。

06

合规底线

严禁讨论时政敏感话题，禁止任何违法违规言论与行为。触碰红线，直接移出社群。

// FAQ

常见问题

申请前建议看完这些。

交钱就一定能加入社群吗？
不能。缴纳 199 元仅代表获得聊天资格，最终录取取决于聊天中的真实思考。不通过全额原路退款。交钱不等于入群。
聊天开启旁听，我的商业想法会泄露吗？
旁听是自愿选项，你可以直接选择一对一语音不开启旁听。聊天过程中，只要你认为内容敏感，可以随时要求关闭旁听，切换私密对话。
如果招募窗口期结束，合格人数不足10人会怎样？
本次种子招募终止，社群项目放弃。已经提交申请的评审流程照常完成。已通过聊天的伙伴另行协商处理方案。
进入社群之后，编号代表等级高低吗？
编号仅作为档案记录标识，S 代表 Seed 种子伙伴，顺序编号，没有任何层级、权益高低之分。
社群交流有哪些红线不能碰？
所有成员必须遵守国家法律法规。社群内禁止讨论时政敏感内容，禁止发表违法违规言论。触碰合规红线会被直接移出社群。
我在国内访问 GitHub 不稳定，可以用其他平台放作品吗？
不需要放作品。申请不要求 GitHub 仓库、不要求作品链接。你在做什么，聊天的时候说就行。
聊天不通过后多久可以重新申请？
本次聊完不通过，3 个月后可以再来聊一次。再次申请需要重新缴纳评审费。
无故缺席聊天会怎样？
提交申请、预约聊天后，无故缺席或临时取消且无合理理由，评审费不予退还。合理理由包括突发疾病、家庭紧急事务、重大设备或网络故障等不可抗因素，需在聊天前 24 小时告知并事后说明。
加入后需要做什么？
每天随手复盘：今天做了什么、卡在哪、怎么处理的。互相追问——你的问题备选方案呢？执行了没有？一个月后这些记录自然攒成一份复盘，帮你看清自己到底干了什么、哪没动。没有强制义务，没有月度交差，但不记录的人会发现群里没什么可聊的。

这是一个开源模板

我们相信社群不该绑在某个人身上。这套规则、筛选流程、网站模板全部公开。 如果你也想在自己的城市、自己的领域，搭一个同样逻辑的社群——直接 fork 这个仓库，改成你自己的就行。
