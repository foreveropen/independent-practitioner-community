# 独立实践者共建实验社群｜种子招募阶段

本社群目前处于种子伙伴筛选阶段，属于一场小规模自治实验。

## 概述

很多独立创作者、开发者、写作者长期独自做事，容易陷入孤独、闭门造车，缺少同频同伴，难以获得理性反馈，归属感缺失，个人潜力难以释放。

我们希望搭建一个由成员共建、依靠规则自治的共同体：成员之间互相校验思考、理性互评，在持续实践中获得归属感，释放个人潜力。

⚠️ **重要前置声明：**
社群不提供现成赚钱方案、不传授变现套路，不承诺收入、项目、工作机会。商业探索、实践试错全部由成员自主完成。归属感、个人成长是共同体环境有可能带来的结果，并非加入社群就可以保证。社群是实验项目，存在招募失败、项目终止的可能性。

本项目目前处于种子实验阶段。社群底层契约、报名流程、风险与止损条件全部公开；社群内部治理、互评细则、后续扩容机制等细节，不在此文档完整对外公布。待种子伙伴入群后，由共同体共同讨论、迭代完善，并可根据试运行情况动态调整。

## 社群核心理念

1. **共建自治**：社群不属于发起者个人，资产、规则由成员共同维护。社群不依附任何单一成员。若发起者或者早期成员离开，认同规则的伙伴仍可继续维持社群运转。
2. **迭代实践**：成员需要持续产出带思考迭代记录的作品，拒绝空想；重视思考过程，而非单纯看最终成果好坏。
3. **理性互评**：鼓励接收他人合理意见，警惕重度傲慢。互评是互相校验思路，不是互相吹捧或者人身攻击。
4. **拒绝闭门造车**：遇到卡点鼓励交流；公域禁止持续宣泄负能量，情绪压力交由轮班树洞官承接。
5. **筛选优先**：我们只接纳认同理念、愿意双向付出的实践者。索取型心态的申请者会在答辩阶段被筛除。
6. **合规底线**：社群内严禁讨论时政、国家相关敏感话题，禁止任何违法违规言论与行为。所有人必须遵守国家法律，一旦触碰红线，直接移出社群。

## 种子招募基础信息

1. **招募窗口期**：90天（从正式对外发布招募文档当日开始计时）
2. **种子伙伴目标**：下限10人，上限15人
   - 窗口期结束，答辩通过人数 ≥10人 → 社群正式启动试运行，开启月度作品提交、互评、树洞官轮值、共建工作；
   - 窗口期结束，答辩通过人数 ＜10人 → 本次种子招募终止，社群项目放弃，不再继续招募。已通过答辩的申请者将另行沟通处理方案。
3. **名额上限**：达到15人，立刻关闭申请通道，不再接收新申请；已提交的申请依旧走完评审流程。
4. **评审费**：199元（初审不通过 / 答辩不通过全额原路退款；无故缺席答辩不退），详见报名指南。
5. **关于"万里挑一"**：万里挑一是理念描述，代表极高人工筛选标准，不代表真实一万个申请者里只能录取一人，不构成录取比例承诺。

## 种子伙伴入群后义务（申请前必读）

1. 每月提交一份附带GitHub仓库、MD文档、多条commit迭代记录的实践作品；
2. 参与伙伴交叉作品互评；
3. 自愿承担一部分社群共建事务：树洞官轮值、GitHub文档维护、评审协助等；
4. 遵守社群文化公约与合规要求，公域理性交流；
5. 共同参与社群规则迭代讨论。

社群不是"付费圈子"，成员需要付出时间精力共建，只想要索取资源、等待别人投喂思路的人不适合。

⚠️ **持续交付要求：** 种子伙伴需按月持续交付作品并参与共建。长期不交付作品、不参与共建的成员，存在被社群劝退的可能。具体劝退标准与流程由种子伙伴入群后共同讨论制定。
