# 独立实践者共建实验社群

> 一个开源的独立实践者社群模板。规则透明，筛选轻量，欢迎 fork 搭建你自己的社群。

本项目处于筹备阶段，申请入口暂未开放。

## 这个社群是干什么的

很多人独立做事，最大的问题不是孤独，是**没有反馈循环**——做了什么、卡在哪、为什么没动，自己看不见。

这个社群做的事很简单：

1. **每天复盘**：成员记录今天做了什么、遇到什么问题、怎么处理的、执行了没有。没有模板压力，随手记。
2. **互相追问**：别人会问你——这个问题你怎么处理的？有没有备选方案？问过谁？最后执行了没有？
3. **暴露自己的不做**：记录摆出来，你一个月没动就是没动。这个认知本身就是收获。
4. **月度沉淀**：一个月的每日记录攒下来，自然形成一份复盘——不是交作业，是你自己一个月到底干了什么、卡在哪、下一步怎么走。
5. **案例成方法**：大家遇到的真实问题和处理方式积累下来，慢慢变成一套可复用的解决问题的方法。

没有义务，没有KPI，没有强制交差。但如果你真的在做事，这里会让你更清楚自己做到了哪、哪没做。

## ⚠️ 前置声明

社群不提供赚钱方案、不传授变现套路，不承诺收入、项目、工作机会。
商业探索、实践试错全部由成员自主完成。
社群是实验项目，存在招募失败、项目终止的可能性。
所有规则以本仓库文档为唯一可信来源。

## 社群核心理念

1. **共建自治**：社群不属于任何个人，规则由成员共同维护。发起人离开，认同规则的人仍可继续运转。
2. **实践复盘**：不追求最终成果多好看，重视每天的记录和追问。做了什么、卡在哪、为什么没动——记下来就是进步。
3. **理性追问**：互相校验思路，不是互相吹捧。问具体问题：备选方案呢？执行了没有？
4. **拒绝闭门造车**：遇到卡点就聊，公域不宣泄负能量。
5. **筛选优先**：只接纳真的在做事、愿意被追问的人。想索取资源的人不适合。
6. **合规底线**：严禁讨论时政敏感话题，禁止违法违规言行。触碰红线直接移出。

## 怎么申请

完整筛选标准见 [selection-criteria.md](selection-criteria.md)。

简要流程：了解社群 → 填表说你在做什么 → 交199元 → 一对一语音聊天（15-30分钟）→ 结果。

不要求GitHub仓库，不要求作品，不要求准备PPT。
聊天是核心：聊你在做什么，也会现场抛一个问题看你怎么想。

## 入群后做什么

- 每天随手复盘记录：今天做了什么、卡在哪、怎么处理的
- 互相追问：你的问题备选方案呢？执行了没有？
- 一个月后，你的每日记录自然攒成一份复盘，帮你看清自己
- 大家的真实案例慢慢积累成解决问题的方法
- 一起讨论迭代社群规则

没有强制义务，没有月度交差。但不记录的人会发现群里没什么可聊的。

## 开源模板

这个仓库的所有内容——规则、筛选流程、网站模板——都可以自由 fork。

这恰恰证明了社群不绑在某个人身上。
